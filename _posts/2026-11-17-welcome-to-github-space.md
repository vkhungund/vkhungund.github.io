This is my first blog post powered by **Jekyll** and hosted on **GitHub Pages**.

## What You Can Write Here
You can use standard Markdown formatting inside any file in the `_posts/` folder:

* **Bold** and *italic* text
* Bullet lists and numbered steps
* Links like [GitHub Docs](https://github.com)
* Code snippets and blockquotes

Every time you add a new dated Markdown file to `_posts/`, it will automatically appear on the home page.
